# 飞书来源范围

每个飞书来源仅递归读取 `root_token` 指定节点及其子节点，不自动扩大到整个知识空间。

- `excluded_node_tokens`：排除指定 Wiki 节点及其子树。
- `excluded_object_ids`：排除底层文档身份（例如 `sheet:对象token`）；用于避免同一题表通过不同 Wiki 快捷入口再次被收录。它只排除该对象，不排除其他子文档。

列表默认空，均只接受管理员配置，不接受模型工具参数。扫描不读取排除对象的内容，直接读取亦拒绝。配置变化参与来源哈希，下一次配置加载撤销旧活动索引，完整同步后只发布允许资料；历史归档不删除。

建议新根节点使用独立 source id，在隔离集合验证后上线；测试配置不要调用生产 `configure_store`，因为它会停用配置未包含的来源。切换前保留原配置、来源ID和活动版本清单，以便回退。修改配置需要重新加载 API 与同步进程。部门及员工权限仍由原授权层执行，排除配置不扩大访问权。
